Features

Everything you need to tame cloud costs.

A focused toolkit that combines real-time visibility, structured data, and a clean REST surface — no bloat, no spreadsheets.

Real-time KPI dashboards

Live monthly burn, projected spend, and variance against budget — rendered through Go HTML templates with sub-second refresh.

Provider distribution

Visualize spend split across AWS, GCP, and Azure. Spot anomalies and rebalance workloads before invoices land.

CRUD expense records

Tag, categorize, and annotate every line item. Full create-read-update-delete flow backed by SQLite for instant search.

REST API surface

Clean JSON endpoints powered by Gin. Integrate CloudSpend data into Slack bots, cron alerts, or internal tooling.

Containerized & tiny

Multi-stage Dockerfile produces a minimal Alpine image under 25MB. Fast cold-starts, predictable rollouts.

Azure-native deploy

Push to Azure Container Registry, deploy to App Service in minutes. Managed scaling without ops overhead.

Architecture

A stack that's deliberately small.

Single Go binary. Embedded SQLite. Server-rendered templates. The whole thing fits in a 25MB container.

Browser
HTML + JS
Go · Gin
REST + templates
SQLite
File-based store
1 · Build

Multi-stage Dockerfile compiles Go binary, strips debug symbols, and packages into an Alpine base image under 25MB.

FROM golang:1.22-alpine AS build
RUN go build -ldflags="-s -w"
FROM alpine:3.19
2 · Push

Image is tagged with commit SHA and pushed to Azure Container Registry. Vulnerability scans run automatically before promotion.

docker push
myacr.azurecr.io/cloudspend:sha-7f3a2b
3 · Deploy

Azure App Service pulls the latest image, runs health checks, and swaps slots for zero-downtime rollouts.

az webapp config container set
--image cloudspend:latest
