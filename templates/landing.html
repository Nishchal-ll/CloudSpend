Architecture

A stack that's deliberately lightweight.

Single compiled Go binary. Embedded SQLite database. Server-side HTML templates. Packaged in a 25MB container.

1 · Build

Multi-stage Dockerfile compiles Go binary with zero CGO dependencies and strips debug symbols into Alpine.

2 · Push

Image tagged with version and pushed to Azure Container Registry (ACR) with automated vulnerability scans.

3 · Deploy

Azure App Service pulls container image and serves the application over HTTPS with health check probes.
